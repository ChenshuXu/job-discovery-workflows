# Career Docs — private document workspace

This workspace owns interview preparation and the sole process register at
context/Interview/active-interviews.md. Use context/00 Knowledge Base Hub.md to locate
materials. Candidate facts come from the user's Career-Ops profile and confirmed input;
do not copy fictional examples into application answers.

Use Job Discovery's gmail-job-reply-review Skill and canonical writer for existing
register updates; technical-interview-prepare owns research/prep documents. Preserve
existing identities, notes, progress and evidence. Keep this workspace private; never
publish personal documents or add a public remote during setup.

The register owns current stages, dates, status and candidate TODOs. Notes link to the
matching Identity section in each company's process-summary.md, which owns identity
context and dated communication history. The same Skill maintains both. Link existing
prep/debrief content instead of repeating it; do not duplicate current-state tables or TODOs.

Process charts use Job Discovery’s process-infographic Skill. Application totals come
from Career-Ops, interview identities/results from the register above, and completed
events from dated evidence. Keep generated snapshots in outputs/<snapshot>/; these
are private derived artifacts, not a second register. Existing alternative layouts
can be passed through explicit paths or a source-linked format adapter.
