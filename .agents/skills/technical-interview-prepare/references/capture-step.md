# 单步采集与落盘

所有采集者（包括主代理）使用此流程。浏览操作仍直接写在 Ego Lite heredoc 中；
`check_capture.py` 只读本地文件，不访问网站，也不能证明页面没有未知限制。

1. 一次 heredoc 最多提交一个搜索、打开一帖或翻一页；同页可做必要输入和一次提交。
   不在循环、Promise.all 或连续导航中跑多条查询/多帖/多页。结束后先读取完整返回和原件，
   检查共享停用消息，再决定下一次浏览。评论展开/切图也以一次动作后保存并观察为边界。
2. 从命令启动就将 stdout/stderr 重定向到独占日志，用 `set -C` 防止覆盖；长命令返回
   session/cell 时等到终态。日志由进程持续写文件，不依赖聊天输出额度或后补拼接。
3. 页面返回后先将实际 URL、标题、完整已获取正文/链接和采集时间写入独占 JSON；不得
   `.slice()` 截断原文。需要作者、楼层、日期等结构化提取时同样立即另存原始提取结果。
   同一 heredoc 内可在保存正文后按需截图，截图失败不丢已存文字；PNG 使用已有独占路径规则。
   BBS 的导航间隔放在下一次动作前；本次动作返回立即取正文，不先固定等待 10 秒而错过
   自动返回的提示。易消失的提示另保存可见提示区域/截图；多次观察可追加快照，不覆盖首帧。

下面是观察与落盘片段，放在完成本次单一页面动作后。`output` 换成本次公司归档下
包含 worker、递增步号的绝对路径；task space、tab 和动作按已观察状态填写，不复制占位值。

```javascript
const fs = await import('node:fs');
const page = await js(String.raw`(() => ({
  url: location.href,
  title: document.title,
  text: document.body?.innerText || '',
  links: [...document.querySelectorAll('a')].map(a => ({text: a.innerText, url: a.href}))
}))()`);
page.captured_at = new Date().toISOString();
fs.writeFileSync(output, JSON.stringify(page, null, 2) + '\n', {flag: 'wx'});
cliLog({capture: output, url: page.url, title: page.title});
// 可在此按需截取同页图片；读取保存结果后，才在新 heredoc 中执行下一次页面动作。
```

4. 运行 `python3 scripts/check_capture.py /absolute/path/to/capture.json`（脚本相对 Skill）。
   **HUMAN_HANDOFF / STOP_SOURCE**：分别按 [联网流程交接规则](research-workflow.md#派发与协作)
   处理人工验证或真实来源限制；交接、通知及恢复要求只在该处维护。
   **REVIEW**：先保存并读取当前提示全文/截图，按实际原因处理；普通表单错误可修正，
   人工验证走 HUMAN_HANDOFF，真实访问限制走 STOP_SOURCE。无法判定时暂停受影响操作，
   向用户呈现实际提示；不把通用标题自动升级为全站封禁，也不把自动返回当作查询成功。
   历史日志仅有“提示信息”标题、正文已丢失时，先查原始记录和截图。仍无法恢复且用户已
   要求诊断/恢复该缺口，可由原来源负责人在原空间观察当前正常入口；旧空间已关闭时记录
   事实后建立替代空间。没有当前验证或真实访问限制，才进行一次原未完成查询并立即完整
   捕获结果。再次遇不明提示就交用户处理，不循环重试；已知封禁/403/429不适用此诊断分支。
   **CLEAR**：还要由当前代理读原文/图判断实际页面是否正常、查询是否生效、是否有新提示。
   它不授权恢复已经停用的来源，也不能替代用户控制交接。不要再自写正文数字正则检测器。
5. 捕获失败或退出非零时保留日志；有正文输出不等于整步成功，没有 JSON 则不能进入下一步。
   原始 HTTP 403/429 若从本次实际响应得到，可加 `http_status`；不能从文字/题号推测状态码。
   用户接管/inactive/unassigned 按上述交接规则处理，不降级为普通捕获错误。
6. 已有缺失原件先查持久归档和原始执行返回；截图失败后的返回也可能带有有效正文。
   恢复材料另存，记录来源执行记录/行号、原采集时间、恢复时间及截断或提取上限，
   原始 worker 文件/旧清单不覆盖。日志中的凭证/签名值按既有规则脱敏并注明；恢复日不是访问日。

同一工具调用可依次完成本步落盘、等待进程终态、运行检查器及读取正文，减少重复调用；
仍须先实际观察本步结果，才发起下一次页面动作。完整日志留档，返回保留退出码/session 等
控制元数据、检查结果和供本步阅读的原文/图片，不重复回显整份历史日志。
